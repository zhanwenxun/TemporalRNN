# TemporalRNN

**Paper:** *Test Case Selection for Recurrent Neural Networks Based on Multi-Perspective Failure-Aware Temporal Features*

This repository contains the implementation and experimental scripts for **TemporalRNN**, together with baseline methods and scripts used to reproduce the experimental results.


## Data, Models, and Generated Test Sets

Due to the large size of the datasets, generated test sets, trained RNN models, and evaluation-set files, they are provided separately through Google Drive:

https://drive.google.com/drive/folders/1X3qFrNMSQTs4mkKA6Qwk22b-C9cz8ms7?usp=sharing

Download the following archives and extract them into the project root directory:

```text
data_and_model.zip
evaluation_set.zip
```

After extraction, the project root should contain:

```text
data/
gen_data/
RNNModels/
evaluation_set/
```

The folders are used as follows:

- `data/`: stores the original datasets and intermediate data files required by model training, prediction extraction, and test-case selection.
- `gen_data/`: stores generated candidate test sets. These files are the candidate pools from which different test-case selection methods choose subsets.
- `RNNModels/`: stores trained RNN models and model-related resources, such as saved LSTM/GRU/BiLSTM models and word-vector resources for text datasets.
- `evaluation_set/`: stores held-out evaluation-set metadata used by the retraining experiments.
- `selected_index/`: generated by the test-case selection scripts. It stores binary selected-index files used by retraining experiments.


## 1. Environment Setup

Install the required dependencies:

```bash
pip install -r requirements.txt
```

A CUDA-enabled environment is recommended for model training and retraining.


## 2. Prepare Data and Prediction Information

If the provided Google Drive archives are already extracted, this step is usually not necessary.

If you need to regenerate the data and intermediate prediction information, run:

```bash
bash prepare.sh
```


## 3. Run TemporalRNN and Baseline Methods

### Baseline Methods for RQ1 and RQ2

```bash
bash rq12_run.sh
```

### RNNtcs

```bash
bash rnntcs_run.sh
```

### TemporalRNN

In the current release, the script below is the main implementation of the TemporalRNN method reported in the paper:

```bash
bash temporalrnn_run.sh
```

This script runs the current TemporalRNN test-case selection process. It first estimates failure-risk scores, then combines high-risk samples with small-margin samples, and finally performs group-balanced sampling based on `(top1_label, top2_label)`.

### TemporalRNN-w/o-GS Variant

```bash
bash temprnn_scores_run.sh
```

The TemporalRNN-w/o-GS variant is used for ablation analysis. It selects test cases mainly according to the TemporalRNN failure-risk score.


## 4. Generate Experimental Results

Experimental results are saved under:

```text
results/
```

Typical output files include:

```text
results/rq1_<dataset>_<model>_results.xlsx
results/rq1_temprnn_scores_<dataset>_<model>.csv
results/temporalrnn/
```

Selected test-case indices are saved under:

```text
selected_index/
```


## 5. Model Retraining Accuracy Improvement

Run the held-out complement retraining experiment:

```bash
bash rq3_run.sh
```

If held-out evaluation metadata is missing, prepare it first, for example:

```bash
python rq3.py -dataset mnist -model_type lstm --prepare_eval_ids
```

Retraining results are saved under:

```text
results/rq3/
```


## 6. Main Scripts

| Script | Description |
|---|---|
| `temporalrnn.py` | Main script for the current TemporalRNN method reported in the paper. |
| `temporalrnn_run.sh` | Runs the current TemporalRNN method on all datasets and RNN models. |
| `temporalrnn_utils.py` | Shared helper functions, such as loading prediction information and training the failure-risk detector. |
| `temprnn_scores.py` | Runs the TemporalRNN-w/o-GS ablation variant. |
| `temprnn_scores_run.sh` | Shell script for the TemporalRNN-w/o-GS ablation variant. |
| `rq12.py` | Runs RQ1/RQ2 experiments for baseline methods. |
| `rnntcs.py` | Runs the RNNtcs baseline. |
| `rq3.py` | Runs retraining with held-out complement evaluation. |
| `data_util.py` | Contains data processing utilities and test-case selection functions. |
| `selection_tools.py` | Contains helper functions for baseline selection methods. |
